📊 Excel to JSON Converter

Chuyển đổi file Excel thành JSON Database

📁
Kéo thả file Excel vào đây hoặc click để chọn file
Hỗ trợ: .xlsx, .xls
📋 Preview dữ liệu (5 dòng đầu tiên)

📝 Hướng dẫn sử dụng:

  1. Chọn file data.xlsx hoặc databarcode.xlsx
  2. Xem preview dữ liệu để kiểm tra
  3. Click "Chuyển đổi sang JSON" để tạo file JSON
  4. File JSON sẽ tự động tải xuống
  5. Đặt file JSON vào thư mục dự án (cùng thư mục với index.html)
  6. Lặp lại cho file thứ 2
